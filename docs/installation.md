# Installation

## Asset Store only
{: .no_toc .text-delta }

## Requirements

- **Unity 2022.3 LTS** or **Unity 6** — verified on both.
- An Editor on **Windows, macOS or Linux**. PreFlight is editor-only tooling: it adds nothing to your player build.
- **No third-party dependencies.** Nothing else to install, no network connection needed at run time — PreFlight makes no network calls and sends no telemetry.

## Install from the Asset Store

1. Purchase PreFlight on the Unity Asset Store under the Unity ID you use for your projects.
2. In the Unity Editor, open **Window → Package Manager**, switch the Packages filter to **My Assets**, find **PreFlight**, and choose **Download**, then **Import**.
3. Import the full package. The package includes the PreFlight editor tooling, the Harborlight Sample (Broken) and its clean twin, the documentation set, and the automated test suite.

## Run Setup (once)

1. Open the Home window: **Tools → Decnet Games → PreFlight**.
2. On the welcome screen, click **Run Setup / Verify Install**.
3. PreFlight answers in its own words: **"PreFlight is ready."**

![Setup report: "PreFlight is ready."]({{ "/assets/images/setup-report.png" | relative_url }})

Run Setup again at any time — it is safe and idempotent. The second run answers **"Already set up — nothing changed."**

![Second setup run: "Already set up — nothing changed."]({{ "/assets/images/setup-second-run.png" | relative_url }})

There is nothing else to configure before your first scan. Set the scope in the **Scan** section and click **Scan This Project** — or rehearse the full loop on the included sample first, as the [Quick Start](./quick-start) does.

## Updating

Updates are delivered through the Asset Store like any other package: re-download the new version in Package Manager (**My Assets**) and import it over the existing install. Your scan settings live in the project, and `preflight-verdict.json` is regenerated by every run, so no migration step is needed.

## Uninstalling

Delete the PreFlight package folder from your project. PreFlight writes only inside your project and to the verdict and report paths shown in the window; removing the package removes the tool. Any `preflight-verdict.json` or exported Markdown report already in your project simply remains as a file — delete it too if you do not want to keep the record.
