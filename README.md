# PreFlight-DOC

Documentation site source for **PreFlight — Project Integrity Scanner** by Decnet Games.

Built with Jekyll + [Just the Docs](https://just-the-docs.com/) (loaded via `remote_theme`) and published with GitHub Pages at:

**https://decnet-games.github.io/PreFlight-DOC/**

## Layout

- `index.md` — Home
- `docs/` — Getting Started, Installation, Quick Start, the five Defect Classes, Dispositions, Repairs, Re-scan Flow, Verdict JSON, Markdown Report, Headless & CI, the Harborlight Sample, Settings, What v1 Is Not, FAQ, Support
- `assets/images/`, `assets/videos/` — the product's real captures and demo media

PreFlight itself is sold exclusively through the Unity Asset Store (publisher: Decnet Games). Nothing in this repository is the product — this repo is documentation only.
